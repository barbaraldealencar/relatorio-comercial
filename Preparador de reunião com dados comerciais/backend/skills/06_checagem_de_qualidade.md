# Skill: Checagem de qualidade antes de entregar o briefing

O GC vai levar estes números para a mesa. Um número errado ou uma notícia velha vira concessão de preço e perda de credibilidade. Antes de fechar o briefing, faça esta checagem. Ela é obrigatória.

## 1. Cada número tem fonte e data
- Todo número citado vem de uma ferramenta desta sessão (ou de um cálculo seu a partir dela) e aparece com **fonte e data**: "Brent US$ 114 (FRED, média de set/26)".
- Número sem fonte não entra. Se você "lembra" de um dado, mas nenhuma ferramenta o trouxe, não use.
- Não arredonde para mudar o sentido ("+4,6%" não vira "quase +5%" num argumento de preço).

## 2. Atualidade
- Use `verificar_atualidade` com tudo o que pretende citar: manchetes, indicadores do setor, fatos do cliente e dados de mercado.
- Item **antigo**: retire, ou cite explicitamente como histórico ("em 2020, o cliente comprou..."), nunca como novidade.
- Item **sem data**: não apresente como atual.
- Notícia de mais de 30 dias não vai para "manchetes que importam".

## 3. Coerência entre blocos
- O mesmo número tem o mesmo valor em todos os blocos (resumo, oportunidades, roteiro).
- As somas fecham: o valor em jogo é igual à soma das oportunidades listadas, ou explique a diferença.
- Os sinais estão certos: "o cliente paga menos que os peers" é oportunidade; "paga mais" é risco.

## 4. Dados internos e sigilo
- Dados de peers nunca identificam outro cliente: use "mediana dos peers" ou "cliente comparável".
- Não copie trechos de e-mail com dados pessoais de contatos (telefone, e-mail pessoal); resuma o conteúdo.
- Dados fictícios de demonstração continuam marcados como fictícios.

## 5. O que fica para o GC decidir
- O briefing **sugere**; quem decide preço, concessão e prazo é o GC.
- Escreva as recomendações como opções com o trade-off ("escalonar custa ~R$ 1,0 mi/mês contra a fórmula"), não como ordem.
- Nunca afirme que algo foi enviado, combinado ou registrado: a ferramenta só lê dados.

## Saída
No fim do briefing, inclua uma seção curta **"Checagem de qualidade"** com:
- quantos itens foram verificados e quantos foram retirados ou marcados como histórico;
- os dados que não puderam ser confirmados (para o GC conferir antes da reunião).
